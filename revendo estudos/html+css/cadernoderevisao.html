Básico de html

paragrafos

de maneira simples aqui você pode escrever de qualquer jeito. porque a aparencia fica por conta do css. mas ainda sim podemos usar algumas 'marcas' para deixar o texto mais organizado.

use 'tag' <h1>, <h2>, <h3> etc... para titulos e subtitulos 'lembrando e titulo e subtitulos e nao tamanho da letra'

use 'tag' <p> para paragrafos

para quebrar uma linha use <br>. para usar uma linha para separar textos use <hr>. para adicionar comentario no meio do codigo use (<!--comentario-->)

abreviações

para usar abrevioações use a 'tag' <abbr> HTML e CSS ,passando o mouse encima você descobre o significado

emoji e simbolos

para usar emoji você poderia simplesmente copiar e color o emoji desejado porem saiba que pode não funcionar em alguns navegadores.

mas para minimizar isso use &#x + (1f913) numero do emoji 🤓. para simbolos use & + (dollar) nome do simbolo $

ancoragem 'links' de navegação na página

para usar links externos use a 'tag' <a href="link-da-pagina">nome</a >

imagens, audios e videos

primeira coisa CUIDADO com direitos autorais, verifique a licença antes de usar.
sites uteis para 'pegar imagens' são unsplash e pexel.

para usar a imagem use 'tag' <img src="localização do arquivo ou site" alt="nome da imagem">.

vale a pena lembrar 2 coisas imagem PNG tem maior qualidade e transparencia, ja JPG tem maior compactação. sempre tente deixar o site mais leve possivel, mas cuidado pra não perder qualidade.

trabalhando com imagens cuidado pois existem varios tamanhos de telas diferentes ex. celular, tablets, monitores enfim.

usando imagens use a 'tag' <picture> e encima disso a 'tag' <source media="(max-width:tamanho maximo )" srcset="localização do arquivo" type="image/png ou jpg"> lembrando cuidado com a ordem das imagens.

usando audios seguem as regras da imagens CUIDADO com direitos autorais e tamanho dos aquivos a serem carregados.

NUNCA esqueça de configurar os audios com parametros certos

quando for usar videos CUIDADO, hospedar no seu proprio site você usa muito trafego de banda e isso pode ficar muito caro para seu cliente, então explique isso para evitar problemas.

Seu navegador não tem compatibilidade com esse video.

De uma maneira resumida é assim que usa midias no seu site. Lembrando cuidado com tamanhos e formatos, pois isso interfere direto na navegação do seu site, quanto mais fluida e limpa for a navegação mais agradavel fica seu site.

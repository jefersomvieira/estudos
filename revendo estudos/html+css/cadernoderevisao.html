Básico de html

paragrafos

de maneira simples aqui você pode escrever de qualquer jeito. porque a aparencia fica por conta do css. mas ainda sim podemos usar algumas 'marcas' para deixar o texto mais organizado.

use 'tag' <h1>, <h2>, <h3> etc... para titulos e subtitulos 'lembrando e titulo e subtitulos e nao tamanho da letra'

use 'tag' <p> para paragrafos

para quebrar uma linha use <br>. para usar uma linha para separar textos use <hr>. para adicionar comentario no meio do codigo use (<!--comentario-->)

emoji e simbolos

para usar emoji você poderia simplesmente copiar e color o emoji desejado porem saiba que pode não funcionar em alguns navegadores.

mas para minimizar isso use &#x + (1f913) numero do emoji 🤓. para simbolos use & + (dollar) nome do simbolo $

imagens e videos

primeira coisa CUIDADO com direitos autorais, verifique a licença antes de usar.
sites uteis para 'pegar imagens' são unsplash e pexel.

para usar a imagem use 'tag' <img src="localização do arquivo ou site" alt="tamanho">.

vale a pena lembrar 2 coisas imagem PNG tem maior qualidade e transparencia, ja JPG tem maior compactação. sempre tente deixar o site mais leve possivel, mas cuidado pra não perder qualidade.
